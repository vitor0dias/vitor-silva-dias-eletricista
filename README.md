# Vitor Silva Dias — site profissional

Site estático de apresentação dos serviços elétricos de Vitor Silva Dias, MEI na Zona Sul de São Paulo.

Endereço público: https://vitor-silva-dias-eletricista.vercel.app/inicio

## Editar

- Conteúdo: `index.html`
- Visual: `styles.css`
- Ano do rodapé: `script.js`
- Imagem: `assets/eletrica-residencial.webp` (imagem ilustrativa)

## Publicar na Vercel

Importe este repositório na Vercel como projeto estático. Não há comando de build nem variáveis de ambiente. Alterações enviadas à branch principal publicam uma nova versão automaticamente quando a integração com GitHub está ativa.

## Dados publicados

Nome empresarial, CNPJ e atividade principal foram conferidos no CCMEI fornecido pelo titular. CPF e endereço completo não são publicados. O telefone, o e-mail e a área de atendimento foram informados pelo titular para uso no site.
